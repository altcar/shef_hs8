    how it works

    20 species from xeno-canto (5 s clips) + ESC-50 negatives → 16 kHz mono → 512-point STFT, 160 hop → 64-band mel → log → 3 one-second windows pooled to 64×32 → standardise → conv 3×3×10 → pool → conv 3×3×20 → pool → dense 64 → 21.
